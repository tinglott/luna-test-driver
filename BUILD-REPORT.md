## Bugs ported from the PA build (all four, fixed here too)

1. **Memory-store deadlock** (`kvstore.py`): `_MemoryBackend.incr`
   held a plain `Lock` while calling `get()`/`set()` — fixed with
   `RLock`. (Only bites the memory backend; the Vercel deployment
   uses Upstash, but the bench tests hit it.)
2. **OAuth state mismatch** (`google_oauth.py`): `Flow.authorization_url`
   generates its OWN state when none is passed — fixed by passing
   `state=state`.
3. **PKCE verifier mismatch** (`google_oauth.py`): fixed with
   `autogenerate_code_verifier=False` (confidential web client
   authenticates with its secret; PKCE is optional there).
4. **Expiry naive/aware TypeError** (`calendar_booking.py`):
   google-auth's `utcnow()` is deliberately naive; stored ISO expiry
   parsed as aware raised `TypeError` on every booking call — fixed
   by normalizing expiry to naive UTC.

Also ported: the Chrome User-Agent transport fix (`brain.py`,
`groq_tts.py`, `groq_whisper.py`) — Cloudflare 1010-blocks custom
UAs on the bench egress proxy. And the `groq_tts.py` Vercel 4.5 MB
response-size guard note, restored (the PA copy had dropped it).
